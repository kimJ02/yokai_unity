## 4. ✅ 전투 배수 체인 (2026-09-10 완료)

원본 `dealDamage`(`:1664`)의 최종 피해식은
`statAtk × dmgMultAll() × mult × vulnMult × lvF × itemDmgVs × rebirthWall × rand(0.9,1.1) × crit`.
**대상과 무관한 항은 `Combat/DamageCalculator`, 대상에 달린 항은 `Enemies/EnemyHealth`가 곱한다**
(계산기가 대상 참조를 갖지 않는 순수 함수라서). 수치는 `Core/CombatModifiers`에 모여 있다.

- [x] **콤보** — 3초 윈도우, 콤보당 피해 +1.2% / 골드 +0.8% (`:742`, `:703`, `:1621`)
- [x] **살기(fury)** — 런 내 처치마다 피해 +0.8% / 공속 +0.4% 누적 (`:702`, `:1825`)
- [x] **연쇄 처치** — 0.8초 내 3킬 이상 시 골드 보너스 (`:704`, `:1829`). 슬로모 연출은 없음
- [x] **레벨 페널티** — 내 레벨 < 몹 레벨이면 레벨당 -5%, 하한 25% / **보스는 50%** (`levelFactor`, `:1651`)
- [x] **성소 버프** — 피해 ×1.3, 이속 ×1.25 (`:1300`). 양방향 전부 구현.
      적 버프는 **매 프레임 다시 계산**한다(`:4414`) — 스폰 보호 중인 성소는 아직 강화하지 않는다
- [x] **취약(vulnT)** — 중력점 장기 노출 시 받는 피해 ×1.2 (`:1663`, `:3817`).
      아이템 '균열의 각인'(`vuln`) 경로도 연결됨 — 때린 적을 3초간 취약으로 만들고 배수가 더 커진다
- [x] 히트스톱(`state.freeze`) — `RunController.Hitstop()`. 지속 피해 틱엔 안 걸린다(`:1686`)
- [x] 스탯형 아이템 항 — `itemMul('dmg')`, 쿨감·받는피해감소·경험치·골드 배수 전부 연결됨
- [ ] **조건부 아이템 항 11종** — `itemDmgVs`(`giantSlayer`·`execute`·`ambush`·`crowd`),
      `lastStand`, `airDmg`, `killSpeed`, `killRage`, `plague`, `deathBlast`, `lifesteal`.
      전부 **피격 순간의 대상/플레이어 상태**가 필요한데 지금 피해 경로에 그 정보가 안 흐른다
- [x] 윤회 장벽 `rebirthWallPlayerDmgMult` (`:741`)
