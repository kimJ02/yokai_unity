# 원본(프로토타입) ↔ Unity 이식 대조표

원본 `reference/project_test.html`(7199줄)과 현재 Unity 구현(`Assets/Scripts`, 30파일 2636줄)을
시스템 단위로 전부 대조한 결과. **비주얼(캐릭터/몹/배경 그림, 파티클, 렌더링 1734줄)은 대조 대상에서
제외** — 사용자 확인 사항(2026-09-08): "캐릭터나 배경 이런 건 달라도 상관없는데 게임 내부 동작은 다 돼야 한다".

작성 2026-09-08. 숫자 뒤 `:NNNN`은 전부 원본 줄 번호.

## 0. 지금 가장 큰 문제 — 게임의 뼈대가 없다

원본은 **로비 ↔ 사냥(런) ↔ 결과**를 오가는 게임이고, 우리는 **끝없이 이어지는 전투 씬 하나**뿐이다.
개별 기능이 아니라 이 구조가 없어서 생긴 차이가 아래 1번 항목 전부다.

| | 원본 | 우리 |
|---|---|---|
| 씬 상태 | `state.scene` = `lobby`/`run`/`pause`/`result` (`:1466`) | 없음 (전투 화면 하나) |
| 사냥 시간 | 일반 90초 · 보스 180초, 끝나면 `endRun('timeout')` (`:695`, `:4412`) | 무제한 |
| 죽으면 | `endRun('dead')` → 결과 화면 → 로비 (`:1927`, `:4354`) | **R키로 그 자리 부활** ← 원본에 없는 것을 우리가 만듦 |
| 부활 | 아이템 '최후의 발악' 보유 시에만, 체력 40%로 **자동** (`:1917`) | R키 수동 부활(원본과 무관) |
| 일시정지 | ESC (`:1026`) | 없음 |
| 강화·전문화 | **로비 UI**에서 (`:6367` 로비, `:6974` 전문화 탭) | 인게임 숫자키 1~7 (임시 디버그) |
| 결과 정산 | 처치수/골드/경험치/토벌 진행도 표시 (`:4366`) | 없음 |
| 세이브 | localStorage 자동 저장 (`:1213`) | 없음 (껐다 켜면 초기화) |

> 사용자 지적 그대로다 — "부활이라는 건 없고, 업그레이드는 ESC 눌러서 밖으로 나와서 하는 것".
> R키 부활은 스프린트 2 때 "런 사이클이 아직 없으니 테스트가 끊기지 않게" 임시로 넣은 것인데
> (`docs/sprint2-handoff-split.md` 확정 사항), 런 사이클을 만들면 **삭제해야 한다**.

| shooter 사수귀 | 거리 유지(300~500) + 투사체 발사 (`:717`) | ✗ |

## 4. 전투 배수 체인 (통째로 없음)

원본 `dealDamage`(`:1664`)의 최종 피해식은
`statAtk × dmgMultAll() × mult × vulnMult × lvF × itemDmgVs × rebirthWall × rand(0.9,1.1) × crit`.
우리 `Combat/DamageCalculator`는 이 중 **`statAtk × mult` · 난수 · 치명타**만 구현돼 있다.

- [ ] **콤보** — 3초 윈도우, 콤보당 피해 +1.2% / 골드 +0.8% (`:742`, `:703`, `:1621`)
- [ ] **살기(fury)** — 런 내 처치마다 피해 +0.8% / 공속 +0.4% 영구 누적 (`:702`, `:1825`)
- [ ] **연쇄 처치** — 0.8초 내 3킬 이상 시 골드 보너스 + 슬로모 (`:704`, `:1829`)
- [ ] **레벨 페널티** — 내 레벨 < 몹 레벨이면 레벨당 -5%, 하한 25% (`levelFactor`, `:729`, `:1651`)
- [ ] **성소 버프 수신** — 피해 ×1.3, 이속 ×1.25, 15초 (`:1300`)
- [ ] **취약(vulnT)** — 중력점 장기 노출 / 아이템으로 부여, 받는 피해 ×1.2 (`:1663`, `:3817`)
- [ ] 히트스톱(`state.freeze`) — 타격감 핵심이라 "연출"로 빼기 애매함 (`:743`, `:1683`)
